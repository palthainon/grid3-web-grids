# Publishing to Smartbox's Online Grids library

Research by an agent on 2026-11-06 from Smartbox's public pages. Nothing was signed in to or uploaded.

## What it is

- **Online Grids**: grids.thinksmartbox.com (grids.sensorysoftware.com is the same site). Users add sets in
  Grid 3 through Grid Explorer > menu > Add grid sets > Online grids. Categories include Accessible apps;
  there is no Websites category.
- Publish from Grid 3: Grid Explorer > menu > Share grid sets > Online Grids tab > Add. Pick the set,
  categories, description and access methods, tick the Terms of Use, press Share. It needs a Smartbox
  account (Grid 3 Settings > Accounts > Smartbox). No review step or fee was found; it appears to go live
  at once. A shared set can be updated or removed later from the same tab.
  Sources: hub.thinksmartbox.com/?p=4464 (2022-05-26), ?p=1765 (2022-01-26), ?p=4375 (2022-08-24).

## Rules found

- Terms of Use (January 2018, grids.thinksmartbox.com/en/terms): uploads are for personal, non-commercial
  use. Uploading lets Smartbox and other users access, use, download and store the set.
- Remove all personal information before upload (Hub ?p=4464). Shared sets are public.
- Not found: rules on sets derived from Smartbox's stock sets, on sets that run JavaScript, or on how an
  update reaches people who already added the set.
- Library symbols are stored as references. Users without that symbol library see grey boxes.

## Before publishing Muse.gridset

1. Ask Smartbox support (thinksmartbox.com/contact): may we publish a set built from the stock WhatsApp set;
   do sets that run page scripts need review; how do updates reach users; are there newer terms.
2. Check muse.ai's terms on automated use of the site.
3. Check the set holds no personal data and list the symbol libraries its cells use.
4. Only then the operator shares it from Grid Explorer with a Smartbox account. Agents must not publish.
